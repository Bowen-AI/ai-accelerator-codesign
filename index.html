Course overview

Build the bridge between AI workloads and chip architecture.

Accelerators are shaped by the operations they execute and the movement of data through the system. This curriculum develops a principled approach to identifying bottlenecks, evaluating trade-offs and proposing hardware improvements that benefit real classes of workloads.

01 · Analyze

Characterize workloads

Quantify FLOPs, memory traffic, arithmetic intensity and the operational differences between Transformer prefill and autoregressive decoding.

02 · Explore

Compare architectures

Study processing arrays, dataflow, SRAM/HBM, bandwidth, utilization, precision and implementation limits.

03 · Recommend

Support design decisions

Make architecture recommendations with controlled experiments, sensitivity analysis and a credible validation plan.

Each module combines university resources, a technical analysis exercise and a short written deliverable. All required exercises run on a CPU-only computer.
